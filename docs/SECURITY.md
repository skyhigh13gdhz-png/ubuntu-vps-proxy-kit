# 安全注意事项

## 不要提交到 GitHub 的内容

以下内容即使仓库是 private 也不建议写入代码或 issue：

- VPS root 密码；
- SSH 私钥；
- 3x-ui 管理员密码；
- 完整 VLESS 分享链接；
- UUID；
- Reality 私钥；
- API Token；
- 未脱敏日志中的凭据。

Reality 公钥本身不是私钥，但完整节点参数仍不应无必要公开。

## 面板

- 不使用默认/弱账号密码；
- 管理面板不要为了“方便”无限制暴露；
- 定期更新 3x-ui/Xray；
- 修改前备份重要配置；
- VPS 供应商安全组与 Ubuntu 本机防火墙要分别检查。

## SSH

部署完成后建议使用 SSH key，确认 key 登录正常后再考虑关闭密码登录。不要在尚未验证 key 可用时直接关闭密码登录，否则可能把自己锁在服务器外。

## 脚本来源

`install.sh` 会从 3x-ui 上游 GitHub 下载安装脚本。生产环境中更严格的做法是固定已审计版本和校验哈希；V1 暂以可维护性优先，后续应加入版本 pinning。
