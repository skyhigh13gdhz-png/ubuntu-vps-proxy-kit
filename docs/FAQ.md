# FAQ

## VPS 在哪里有限制吗？

没有。v1.0 不限定马来西亚、日本、新加坡、美国等地区。真正关键的是客户端所在地到 VPS 的可达性和线路质量。

## 为什么不在安装前强制让我用大陆手机测试？

因为正常安装路径应该尽量自动化。服务端自动检查只能做方向性预检，最终导入节点实测已经能验证整条链。大陆手机临时 listener 测试只在节点连接失败时启用。

## VPS 自己 ping 中国 IP 能证明大陆能连接 VPS 吗？

不能。网络可能存在方向性过滤或非对称路由。

## 为什么不自动修改防火墙放行所有端口？

因为云厂商安全组和系统防火墙差异很大，脚本不应该为了“保证成功”扩大攻击面。它会检测并提示，不会静默放开所有端口。

## 为什么面板只绑定 127.0.0.1？

代理入口需要公网开放，但管理面板没有必要。SSH Tunnel 更安全。

## 为什么不用 8.8.8.8？

不是说 Google DNS 一定不能用，而是项目希望 DNS 出口与 VPS 位置尽可能一致，并减少公共递归器地域识别带来的变量，所以默认使用本地 Unbound。

## `198.18.0.x` 是 DNS 泄漏吗？

不一定。在 Shadowrocket/TUN/Fake-IP 环境中，这是常见虚拟地址范围。

## 为什么 Reality Target 不自动填 www.apple.com？

Target 不应该靠“大家都这么填”决定。工具会检查候选站点 TLS 1.3/HTTP2，但不把某个热门站写死为默认。

## 为什么不自动创建 3X-UI inbound？

v1.0 不直接操作 3X-UI 私有 SQLite 结构。稳定性优先于表面的一键化；等有稳定官方 API 后再升级。
